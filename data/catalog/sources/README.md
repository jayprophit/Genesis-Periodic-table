# Element reference snapshots

Retrieved 2026-09-08 from https://pubchem.ncbi.nlm.nih.gov/rest/pug/periodictable/JSON and https://www.ciaaw.org/atomic-weights.htm.

The PubChem table is a compiled reference, not proof that every field is measured. Values retain source identity and are labelled REPORTED; superheavy configurations are PREDICTED. Bulk physical properties for Z >= 104 are withheld pending property-specific qualification. CIAAW intervals and parenthesized uncertainties are preserved verbatim; absence of a standard atomic weight is NOT_APPLICABLE, never replaced by an isotope mass number. Temperatures in the PubChem periodic-table download are kelvin, ionization energies eV, densities g/cm3; density and phase conditions must be checked against the element page before scientific reuse.

Regeneration uses these snapshots offline. Update snapshots deliberately and review the resulting diff. Catalogue status indicates presence of a curated chapter, not peer review or validation success.
