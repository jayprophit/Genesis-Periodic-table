# Universal Schema

The universal MAT schema defines how records, states, measurements, evidence and relationships are represented across disciplines.

Its goal is not to collapse every scientific phenomenon into one table row, but to ensure that every record is internally consistent, traceable and machine-readable.

Core schema components:

- identity;
- state;
- measurement;
- provenance;
- relationship;
- uncertainty;
- null-state;
- evidence grade;
- source.
