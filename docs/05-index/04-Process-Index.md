# MAT Process Index

## Purpose

This index captures the transformation pathways, fabrication routes, and process metadata relevant to MAT records.

---

## 1. Process Categories

Process entries may include:

- thermal processes;
- mechanical processes;
- chemical synthesis;
- electrochemical processes;
- electromagnetic processing;
- photonic processing;
- plasma processes;
- vacuum deposition;
- additive manufacturing;
- biological or biochemical processing;
- nuclear transformation.

---

## 2. Indexing Fields

A process entry should track:

- process ID;
- process type;
- inputs;
- outputs;
- conditions;
- source provenance;
- associated material records.

---

## 3. Typical Use

Processes matter because material properties can depend strongly on how a material was made, modified, or exposed to conditions over time.

The process index is therefore not a secondary list; it is a core MAT scientific structure.
