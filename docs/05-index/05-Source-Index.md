# MAT Source Index

## Purpose

The Source Index provides human-readable navigation into MAT's global source registry.

---

# Source ID Format

```text
SRC-000001
SRC-000002
SRC-000003
```

# Primary Origin

Where a database reproduces data originating in a paper, MAT should retain both:

```text
DISTRIBUTION SOURCE
```

and:

```text
ORIGINAL SCIENTIFIC SOURCE
```

where known.
