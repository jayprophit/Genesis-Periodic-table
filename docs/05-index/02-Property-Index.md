# MAT Property Index

## Purpose

This file groups and indexes the material properties, process properties, and state variables used across MAT records.

---

## 1. Property Families

Property entries can be grouped into:

- identity properties;
- nuclear properties;
- electronic properties;
- electromagnetic properties;
- optical properties;
- thermal properties;
- mechanical properties;
- process properties;
- environmental properties;
- safety and hazard properties.

---

## 2. Typical Property Format

A property entry should be searchable by:

- property ID;
- property name;
- category;
- associated material state;
- units;
- evidence status;
- record references.

---

## 3. Example Property Entries

```text
identity.atomic-number
nuclear.half-life
thermal.melting-point
mechanical.youngs-modulus
magnetic.saturation-magnetization
optical.refractive-index
```

---

## 4. Indexing Rule

The property index should remain descriptive and stable. The detailed value and provenance remain in the record itself.
