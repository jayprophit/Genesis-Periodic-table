# MAT References

## Purpose

This reference list provides a place for the primary literature, standards, datasets, and methodological sources that inform MAT.

---

## 1. Reference Types

MAT references may include:

- journal articles;
- textbooks and handbooks;
- standards documents;
- government or institutional reports;
- technical datasets;
- process or test method references;
- patents and disclosures;
- historical archival works.

---

## 2. Reference Handling Rules

Each reference should retain at least:

- author(s) or institution;
- title;
- year;
- source or publication;
- DOI or identifier if available;
- whether the reference is primary, secondary, or historical.
