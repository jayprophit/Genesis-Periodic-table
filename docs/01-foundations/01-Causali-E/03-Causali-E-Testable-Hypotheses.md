# Causali E Testable Hypotheses

This section identifies which portions of the original framework can be translated into testable claims.

## Candidate tests
- Does a change in state A under constraints B produce predictable outcome distributions in controlled experiments?
- Can a system-state model reproduce observed transitions under varying conditions?
- Are branching outcomes mathematically identifiable from data?
- Is backward inference statistically useful without implying retrocausality?

## Requirements for a valid hypothesis
Each hypothesis should define:

1. the variables;
2. the measurement process;
3. the expected relation or behaviour;
4. how it would be falsified;
5. the evidence standard.

Hypotheses that cannot be tested remain conceptual exercises rather than scientific claims.
