# Causali E Formalization

## Purpose

This document is the formal scientific interpretation of the original Causali E concept.

Its purpose is not to convert historical theory into accepted law. Its purpose is to separate the following layers clearly:

- original historical text;
- conceptual analogy or symbolic language;
- mathematically defined model;
- experimentally testable prediction;
- scientifically provisional or rejected hypothesis.

---

## 1. Conceptual Mapping

The original framework can be mapped into a general state-space representation:

\[
S_{t+1} = F(S_t, A, B, E, t)
\]

where:

- \(S_t\) = current system state;
- \(A\) = intervention, transition, or causal action;
- \(B\) = retained conditions, constraints, or boundary assumptions;
- \(E\) = relevant environment or state variables;
- \(t\) = time or process stage.

This representation is intentionally generic. It does not imply that all physical systems are governed by a single universal causal operator.

---

## 2. Scientific Interpretation

The original triadic language can be restated as a causal inference problem:

- A: what is changed or perturbed;
- B: what is kept fixed or constrained;
- C: what state or distribution results.

In a materials context, this becomes:

- A = processing, field, stimulus, environment, or synthesis step;
- B = sample identity, composition, structure, phase, or boundary conditions;
- C = resulting property, phase, response, transformation, or failure mode.

A distinction is therefore maintained between:

- historical Causali E language;
- formal causal model;
- empirical material-state description.

---

## 3. Required Formal Conditions

Any formalized use of Causali E must define:

- variables and their meanings;
- domains and allowable values;
- units for each measured quantity;
- assumptions and constraints;
- initial conditions;
- boundary conditions;
- operator definitions;
- expected outputs or state transitions;
- failure modes or invalid domain regions.

Without these, a symbolic expression is not a scientific model.

---

## 4. Relation to State Variables in MAT

The MAT data architecture already requires that material identity be contextualized by:

- composition;
- phase;
- structure;
- time;
- scale;
- environment;
- process history;
- uncertainty and provenance.

This means that a formal causal model may be valid only within a defined MAT state signature.

For example, a transformation may be written conceptually as:

\[
M_{state,2} = F(M_{state,1}, A, B, E, t)
\]

but only if each variable is explicitly described and the state transition is tied to measured conditions.

---

## 5. Operational Use in MAT

Within MAT, Causali E may be used as a structured language for:

- process-to-property mapping;
- state transitions under controlled stimulus;
- contextual inference from process history;
- failure analysis and negative-result interpretation;
- graph-based relationships between conditions and outcomes.

It should not be treated as a replacement for measured data or established scientific law.

---

## 6. Scientific Guardrails

This formalization does not assert:

- that all systems reduce to one universal causal equation;
- that symbolic similarity proves physical equivalence;
- that the original theory is established physics;
- that any inferred causality is guaranteed to be uniquely identifiable.

It only provides a disciplined path for converting a conceptual framework into a testable model.

---

## 7. Minimum Acceptable Formal Statement

A valid MAT formalization must include, at minimum:

1. a clear statement of scope;
2. a defined object or state;
3. the intervention or forcing term;
4. the constraints or retained conditions;
5. the environment and time context;
6. the measurable outcome;
7. the data and evidence required to test it;
8. explicit conditions under which it would be rejected or falsified.

This is the minimum standard for making Causali E scientifically usable within MAT.
