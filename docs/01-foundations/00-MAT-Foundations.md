# MAT Foundations

MAT is built on the principle that matter can only be understood reliably when its composition, state, conditions, evidence and history are all represented explicitly.

The foundations layer establishes the conceptual and scientific ground rules for MAT, including the relationship between original theory and modern scientific practice.

- Causali E retains the original authorial theory as a historical document.
- Formalization converts conceptual language into clearly defined mathematical and scientific terms.
- Scientific status distinguishes established principles from hypotheses.
- Data architecture defines how MAT records and measurements are structured.
