# MAT Visual System

## Purpose

MAT visual standards ensure scientific communication remains clear, consistent, and traceable.

The goal is not merely aesthetic consistency. It is to make diagrams, tables, graphs, and models semantically clear while preserving the underlying data provenance.

---

## 1. Design Principles

MAT visual outputs must:

- distinguish measured, derived, and theoretical values;
- retain relevant units and conditions;
- use consistent labels for uncertainty and confidence;
- preserve the state context of the material or process;
- avoid implying more certainty than is justified;
- label historical, hypothetical, and reviewed material separately;
- include source or provenance information when the figure carries scientific weight.

---

## 2. Core Visual Classes

MAT supports the following visual categories:

- process diagrams;
- phase or state diagrams;
- spectra and response curves;
- tables of measurements;
- property comparison plots;
- structural or lattice models;
- 3D material models;
- provenance and relationship trees;
- uncertainty plots.

Each class should use a consistent style but remain adaptable to the variable being represented.

---

## 3. Scientific Communication Rules

Visuals should never:

- silently convert uncertainty into certainty;
- hide a missing or null state;
- present a model output as a measured result without annotation;
- omit conditions such as temperature, pressure, field, atmosphere, or scale;
- merge distinct material states into one figure without state labels.

---

## 4. Metadata Requirements

A figure or visual asset should carry metadata including:

- figure or asset ID;
- record or state to which it applies;
- data source;
- measurement or simulation method;
- relevant conditions;
- date or version;
- whether it is measured, derived, or illustrative.

---

## 5. Visual Integrity

A visual is not merely descriptive. It is evidence-bearing when used to support a claim.

Therefore, MAT treats visual outputs as scientific objects requiring provenance, review, and explicit status classification.
