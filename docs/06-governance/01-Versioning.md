# MAT Versioning

## Purpose

MAT uses versioning to preserve scientific lineage while allowing corrections and improvements.

---

## 1. Record Versioning

Each MAT record should carry:

- record ID;
- record version;
- schema version;
- date of last update;
- status;
- supersession target where relevant.

A change in data or interpretation does not necessarily require a new material identity, but it should require a clear record update.

---

## 2. Schema Versioning

The MAT data schema is versioned separately from record content.

This avoids conflating:

- a change in the template or fields;
- a correction to an individual record;
- a scientific revision of a material claim.

---

## 3. Supersession Rules

If a record is revised, the new version should mark the prior version as:

- superseded;
- corrected;
- replaced;
- archived as historical context.

The old record should remain traceable and searchable.

---

## 4. Documentation Versioning

Documentation and governance files evolve separately from the record set.

This allows the project to maintain stable scientific standards while continuing to refine the content layer.
