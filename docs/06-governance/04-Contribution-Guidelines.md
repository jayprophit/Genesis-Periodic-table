# MAT Contribution Guidelines

## Purpose

Contributions should improve MAT without compromising scientific traceability.

---

# Contribution Types

Contributions may include:

```text
DATA
SOURCE
CORRECTION
CALCULATION
CODE
VISUAL
DOCUMENTATION
REVIEW
THEORY
HYPOTHESIS
EXPERIMENT
```

---

# Data Contribution

Provide:

```yaml
record_id:
property:
value:
unit:
conditions:
source:
evidence_type:
```

where applicable.

---

# Correction

A correction should identify:

```text
CURRENT VALUE
PROPOSED VALUE
REASON
SOURCE
```

---

# Theory Contribution

New theoretical work must be clearly identified as:

```text
HYPOTHESIS
MODEL
SPECULATION
```

unless it is already part of established science.

---

# Code Contribution

Code should identify:

- purpose;
- dependencies;
- version;
- input/output;
- reproducibility.

---

# Visual Contribution

Visuals should comply with the MAT Visual System.

---

# Source Contribution

Prefer persistent scientific identifiers where available.

---

# Contributor Conduct

Scientific disagreement should address:

- data;
- mathematics;
- methodology;
- evidence.

Personal authority alone is not evidence.

---
