# How to Use MAT

MAT can be read at several levels.

## Level 1 — Human Reference

Open a numbered MAT record and read it as a scientific reference entry.

The main Markdown record provides the human-readable description.

---

## Level 2 — Detailed Scientific Data

Follow tables and data files associated with the record.

These contain individual measurements, units, conditions, uncertainties and evidence information.

---

## Level 3 — Relationships

Follow identifiers linking a record to:

- isotopes;
- compounds;
- materials;
- processes;
- environments;
- experiments;
- sources;
- applications.

---

## Level 4 — Visualisation

Each record may contain associated:

- images;
- diagrams;
- graphs;
- plots;
- tables;
- three-dimensional models;
- spectral visualisations;
- field visualisations.

Visual assets must reference the data from which they were produced whenever applicable.

---

## Level 5 — Machine Processing

Structured MAT data may eventually be processed computationally for:

- comparison;
- filtering;
- graph traversal;
- simulation input;
- statistical analysis;
- optimisation;
- machine learning;
- materials discovery.

---

## Reading Evidence

A value should never be interpreted without considering its evidence status.

The reader should distinguish between:

- measured;
- independently reproduced;
- theoretically calculated;
- computationally predicted;
- experimental;
- historical;
- hypothetical;
- unverified.
