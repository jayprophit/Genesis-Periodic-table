# MAT Reading Guide

MAT is a layered system.

1. Read the front matter to understand the scope and purpose.
2. Read the foundations to understand the conceptual and scientific background.
3. Read the data architecture to understand how records and measurements are structured.
4. Use the indices to navigate to the relevant record or concept.
5. Check evidence and provenance before treating a value as established fact.
6. Treat the original theory as historical context, not as automatic scientific truth.
