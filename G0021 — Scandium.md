56. Scandium supply is a process problem

Scandium is not extraordinarily rare in the crust in the way its market availability might suggest.

Scandium changes the Genesis dataset in five major ways.

First, it begins the 3d series:

\boxed{

\rightarrow
[Ar]3d^14s^2
}

meaning we now need to track d-electron count, crystal-field state and d-band physics systematically.

\boxed{

+
\text{small Sc}
\rightarrow
Al_3Sc_{\rm nano}
\rightarrow
\text{major strength/recrystallisation change}
}

so mass fraction and functional importance are completely different variables.

\boxed{
Sc^{3+}\text{ replacing }Zr^{4+}
\rightarrow
V_O
\rightarrow

meaning an intentionally created missing atom can be the part of the material that performs the useful transport function.

\boxed{
T\uparrow
\rightarrow
\text{transverse F vibration}\uparrow
\rightarrow
L\downarrow

and that composition can potentially tune a framework from positive through near-zero to negative expansion.

\boxed{
T_c=37.6\ {\rm K}
\quad\text{at}\quad
P\approx243\ {\rm GPa}
}

experimentally, while hydrogen-rich scandium compounds open still higher-T_c theoretical branches.
